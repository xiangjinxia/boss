# 功能演示录屏

这些文件来自本次通过的 Playwright 真实浏览器验收，浏览器实际连接 Spring Boot 和 MySQL，没有录音讲解。

- `01-seller.webm`：卖家登录、图片上传、发布待审核商品，随后接受买家订单。
- `02-admin.webm`：管理员登录、审核上架和查看统计图表。
- `03-buyer.webm`：买家收藏、留言、刷新验证、下单和确认完成。
- `04-market-mobile.webm`：访客搜索与 375px 手机浏览。

三个角色是同时打开的独立浏览器上下文，因此录屏有等待另一角色操作的片段。正式答辩建议参考《运行与答辩指南》重新录制个人讲解。WebM 可用 Chrome、Edge 或 VLC 打开。
