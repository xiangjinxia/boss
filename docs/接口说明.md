# REST API 接口说明

基础路径 `/api`，JSON UTF-8。成功响应 `{"code":0,"message":"ok","data":...}`；失败响应同结构，data 为 null，HTTP 状态码和 code 一致。401 未登录/令牌失效；403 权限不足；404 不存在/私有记录；409 状态冲突；400 参数不合法；413 上传过大。

登录响应包含 token 和 user。需要登录的接口发送 `Authorization: Bearer <token>`，不使用 Cookie 会话。公开 GET 可带令牌，以查看本人私有商品。金额为十进制数；时间按北京时间展示。数据库字段在响应中使用下划线，请求 DTO 使用 camelCase。

## 账号

| 方法 | 路径 | 请求/说明 | 权限 |
| --- | --- | --- | --- |
| GET | /health | 数据库探测与服务名 | 公开 |
| POST | /auth/register | username、password、nickname；固定 STUDENT | 公开 |
| POST | /auth/login | username、password → token、user | 公开 |
| POST | /auth/logout | 撤销当前令牌 | 登录 |
| GET | /me | 当前个人资料，不含密码哈希 | 登录 |
| PUT | /me | nickname、bio、avatar；头像为本人上传路径或空串 | 登录 |

账号 4–24 位字母数字下划线，密码 8–64 字，昵称 1–24 字，签名至多 200 字。

## 商品和个人记录

| 方法 | 路径 | 请求/说明 | 权限 |
| --- | --- | --- | --- |
| GET | /categories | 启用分类与当前在售数量 | 公开 |
| GET | /public/stats | 学生数、公开在售数、累计成交笔数 | 公开 |
| GET | /goods | q/category/min/max/days/sort/page/size | 公开 |
| GET | /goods/{id} | 详情、图片数组、当前收藏状态 | 公开状态或卖家/管理员 |
| POST | /goods | 商品 DTO；初始 PENDING → id | 登录 |
| PUT | /goods/{id} | 商品 DTO；重新 PENDING | 本人，非预订/售出 |
| POST | /goods/{id}/offline | 下架，取消待确认订单 | 本人，非预订/售出 |
| POST | /uploads | multipart 表单 file → url | 登录 |
| GET | /me/goods | 本人商品及状态、驳回原因 | 登录 |
| GET | /me/summary | published、favorites、buying、selling | 登录 |
| GET | /me/favorites | 本人收藏商品，含已下架状态 | 登录 |
| PUT | /goods/{id}/favorite | 幂等收藏 | 登录 |
| DELETE | /goods/{id}/favorite | 幂等取消收藏 | 登录 |

列表返回 `{items,total,page,size}`。page≥1，size 1–48，默认 12；sort 支持 newest、price_asc、price_desc；days 1–365；价格非负且 min≤max。q 对标题、描述进行参数化 LIKE 查询。公开列表只包括正常卖家的 LISTED 商品。

商品 DTO 示例：

```json
{
  "title": "数据结构教材",
  "categoryId": 1,
  "price": 25.50,
  "conditionLevel": "九成新",
  "description": "无缺页，校内面交。",
  "images": ["/uploads/服务器返回的UUID.png"]
}
```

title 1–80 字，description 1–3000 字，price 0.01–999999.99、最多两位小数，images 1–5 张。成色为 全新/几乎全新/九成新/八成新/有使用痕迹。图片不能填写任意外链，须本人上传或原商品已有图片。

## 留言与举报

| 方法 | 路径 | 请求/说明 | 权限 |
| --- | --- | --- | --- |
| GET | /goods/{id}/messages | 留言与回复原文，按时间正序 | 与商品详情一致 |
| POST | /goods/{id}/messages | content、可空 replyToId | 登录；仅卖家可带回复 ID |
| GET | /me/messages | 本人发出、自己商品收到、回复本人，最近 200 条 | 登录 |
| POST | /reports | goodsId、reason → id | 登录 |
| GET | /me/reports | 本人举报和处理结果 | 登录 |

留言/举报至多 500 字。replyToId 须属于同一商品；当前非在售/预订商品不接受新留言。举报处理记录不删除，重复待处理举报返回 409。

## 订单

| 方法 | 路径 | 请求/说明 | 权限 |
| --- | --- | --- | --- |
| POST | /orders | goodsId → id；金额由后端读取 | 买家，非自己商品 |
| GET | /me/orders?side=buying | 本人购买记录 | 登录 |
| GET | /me/orders?side=selling | 本人出售记录 | 登录 |
| POST | /orders/{id}/actions | action、可选 reason | 对应买卖双方 |

action=confirm（卖家接受）、reject（卖家拒绝）、cancel（任一方取消）、complete（买家确认完成）。非法角色返回 403，非法状态或重复处理返回 409。前端不能自行传 amount、buyerId、sellerId 或状态。

## 管理员

全部需要 ADMIN，所有修改记录 audit_log。

| 方法 | 路径 | 请求/说明 |
| --- | --- | --- |
| GET | /admin/dashboard | kpi、from/to（1–90 天），返回累计 kpi、区间 period/trend、categories、definition |
| GET | /admin/goods | status、q、page/size，返回分页 |
| POST | /admin/goods/{id}/review | action=approve/reject/offline；驳回/下架必填 reason |
| GET | /admin/users | q 匹配账号/昵称、page/size，返回分页 |
| POST | /admin/users/{id}/status | action=disable/enable；不能禁用管理员或未完成面交用户 |
| GET | /admin/reports | status、page/size，返回分页 |
| POST | /admin/reports/{id}/handle | action=resolve/reject，必填 reason |
| GET | /admin/orders | status、buyer、seller、from、to；日期 YYYY-MM-DD，to 含当天，page/size 返回分页 |
| GET | /admin/audit | page/size 分页操作审计 |

所有管理列表返回 {items,total,page,size}，默认 20 条，size 1–100、page 1–100000。公共集市、卖家商品/评价、通知也使用服务端分页。个人商品、订单、收藏和举报仍返回完整个人列表，个人留言最多 200 条。


## V1.1 推荐、卖家与评价

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| GET | /discovery?size=4 | size 1–12；recommended/popular/mode/profile/priceCenter/method；推荐含 reason/score_parts/score | 公开，带令牌时按收藏偏好 |
| GET | /announcements | 最近 20 条已发布公告，置顶优先 | 公开 |
| GET | /sellers/{id}?page=1&size=8 | profile/stats/goods；goods 为分页 | 正常账号公开 |
| GET | /sellers/{id}/reviews?page=1&size=10 | 已完成订单评价分页，不返回内部订单号 | 正常账号公开 |
| GET | /orders/{id} | 订单、events 事件列表、review 评价列表 | 对应双方或管理员查询 |
| POST | /orders/{id}/review | rating 1–5 整数、content 5–500 字 → id | 对应已完成订单的买家，一次 |

推荐字段实际名称为 recommendation_reason、recommendation_score、score_parts。profile 为常收藏类别及数量，favoriteCount 为参与计算的收藏数量。没有偏好时 mode=DISCOVERY，否则 PERSONALIZED。评分细节见完整功能说明；不返回其他用户的收藏明细。

## V1.1 站内通知

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /me/notifications | unread=false/true、page/size → items,total,unread,page,size；unread 为该用户全部未读数量 |
| POST | /me/notifications/{id}/read | 标为已读；他人 ID 返回 404 |
| POST | /me/notifications/read-all | 标记当前账号全部通知已读 |

全部需要登录。通知内容与跳转路径由后端业务生成，业务与通知同事务提交。

## V1.1 管理配置

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /admin/categories | page/size 分页，含关联 goods_count |
| POST | /admin/categories | name、icon、sortOrder、status → id |
| PUT | /admin/categories/{id} | 同上；停用阻止后续发布，不隐藏既有商品 |
| DELETE | /admin/categories/{id} | 无商品引用才能删除，否则 409 |
| GET | /admin/announcements | page/size，含草稿与发布 |
| POST | /admin/announcements | title、content、status、pinned → id |
| PUT | /admin/announcements/{id} | 同上；PUBLISHED 即公开 |
| DELETE | /admin/announcements/{id} | 删除并记录日志 |

分类 name 最多 32 字；icon 为 book/laptop/coffee/bike/shirt/box/camera/leaf；sortOrder 0–9999；status=ACTIVE/INACTIVE。公告 title 最多 80、content 最多 2000 字，status=DRAFT/PUBLISHED，pinned 为布尔值。配置修改全部需要管理员权限并审计。
